# A11-ASS

课程项目作品集 —— 宠物医院 MCP 与文档上传工具。

## 目录说明

| 目录/文件 | 说明 |
|---|---|
| `pet-hospital-server/` | 宠物医院后端（Go，REST API） |
| `pet-hospital-mcp/` | 宠物医院 MCP Server（Python，MCP 2026-07-28 协议） |
| `anythingllm-mcp/` | AnythingLLM MCP Server（Python，向量化知识库对话） |
| `upload.html` | AnythingLLM 文档上传 + 向量化网页 |

## 技术栈

- Go —— 宠物医院 REST API 后端
- Python + MCP SDK 2.0 —— 两个 MCP Server（Streamable HTTP）
- HTML/JS —— 文档上传前端
