## Chat-Stream-Tool-FileOps

这是一个基于 Python 的文件操作工具集合。

### 功能
该工具集合提供了以下功能：
- 获取当前电脑的日期和时间
- 计算闰年
- 获取当前工作目录
- 列出指定目录下所有文件和子目录
- 获取指定文件的类型、扩展名和大小
- 读取指定的纯文本文件内容
- 在指定目录下创建新的纯文本文件
- 编辑指定文件的内容（覆盖式写入）
- 创建新目录
- 删除目录（非空）
- 删除文件
- 重命名文件或目录

### 工具列表
以下是包含的 12 个工具及其用法说明：
- `getDate`: 获取当前电脑的日期和时间。
- `isLeapYear`: 计算输入的年份是否为闰年。
- `getCwd`: 获取当前工作目录。
- `listDir`: 列出指定目录下所有文件和子目录。
- `getFileType`: 获取指定文件的类型、扩展名和大小。
- `readFile`: 读取指定的纯文本文件内容。
- `createFile`: 在指定目录下创建新的纯文本文件。
- `editFile`: 编辑指定文件的内容（覆盖式写入）。
- `mkdir`: 创建新目录。
- `rmdir`: 删除目录（非空）。
- `deleteFile`: 删除文件。
- `rename`: 重命名文件或目录。

### 用法说明
具体用法请参考每个工具的文档说明。
