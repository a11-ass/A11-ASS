# Practice01 提示词记录

## 提示词1（开发一次性对话 + config.ini）
请用 Python 写一个最简单的、和大语言模型一次性对话的程序。
要求：尽量简单，不要冗余设计，不要过度设计，不要复杂设计。
- 用一个 config.ini 文件记录 LLM 的配置（接口地址 base_url、密钥 api_key、模型名 model）。
- 程序读取 config.ini，调用 OpenAI 兼容的 /chat/completions 接口。
- 非流式（stream=False），用户输入一句话，打印模型的一次回复即可。

## 提示词2（改造成打字机流式输出）
在上面一次性对话程序的基础上，把输出改造成“打字机”样式的流式（Stream）输出。
要求：尽量简单，不要过度设计。
- 把请求参数 stream 设为 True。
- 逐行解析 SSE 的 data: 片段，遇到 [DONE] 结束。
- 每收到一个内容片段就立刻 print 出来（end=""，flush=True），实现打字机效果。
