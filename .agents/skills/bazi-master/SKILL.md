# 八字排盘 · 多流派解读（bazi-master）

本技能 = **确定性排盘引擎** + **三大流派解读框架**。先算出准确四柱，再按用户选定的流派给出结构化解读。
排盘是数学（天文算法），可验证；解读是传统术数方法论，本技能只提炼方法、不背书其预测效力。

## 使用说明

**擅长**
- 对任意出生时间，产出可复核的四柱、十神、纳音、五行分布、十二长生、神煞、旬空、大运（顺逆/起运/十步运）。
- 按盲派、平衡论、黄勇智三种流派之一，给出旺衰、用神、六亲、财官、婚姻、事业、健康等维度的解读。
- 从 60+ 篇命理资料中定位相关素材（见 `references/index.md`）。

**不擅长**
- 命理"准不准"的科学性论证——传统术数，只提炼方法。
- 真太阳时对时辰的换算（引擎暂按用户所给"北京时间"直接排盘；若用户给了出生地经度，可提示"如需真太阳时请告知，本版按输入时间直排"）。
- 紫微斗数、六爻、奇门等其它术数。
- 逐岁流年应期的精确计算——给原则与应期信号，具体落地需结合命局组合。

## 回答工作流

> 原则：**先排盘，后解读；流派由用户定，不选则默认「五行相对平衡论」。**

### Step 1 · 收集信息
向用户确认（缺什么问什么，不要瞎猜）：
- **出生时间**：年-月-日 时:分（按北京时间；若用户给的是农历，先转公历再排）。
- **性别**：男 / 女（决定大运顺逆）。
- **出生地**（可选）：仅用于真太阳时提示；本版引擎按输入时间直排。
- 若用户只写"1990年X月X日"没写时辰：先排到日柱，明确告知"缺时辰无法排时柱与大运"，请补时辰。

### Step 2 · 排盘（调用引擎，必做）
用 Bash 运行脚本（路径以本技能 `scripts/bazi_calc.py` 为准）：

```
python <skill>/scripts/bazi_calc.py "YYYY-MM-DD HH:MM" 男
python <skill>/scripts/bazi_calc.py "YYYY-MM-DD HH:MM" 女
```

- 输出包含：四柱、十神、纳音、五行（含藏干）、日干、旬空、十二长生、神煞、大运（顺逆/起运岁数/交运日/十步运）。
- **校验**：年柱以立春为界（如 2 月 4 日前出生属上一年）；月柱以交节为界；23:00 起为次日（晚子时）；大运顺逆按年干阴阳+性别。
- 把排盘结果原样呈现给用户（或转写为表格），再进入解读。

### Step 3 · 选定流派并解读
询问用户解读口径（盲派 / 平衡论 / 黄勇智），或按默认（平衡论）进行。然后**加载对应 reference 文件**并按其方法论产出解读：
- 盲派 → 读取 `references/school_mang.md`
- 五行相对平衡论（新派）→ 读取 `references/school_balance.md`
- 黄勇智体系 → 读取 `references/school_huang.md`

各 reference 内含：核心模型、旺衰/格局/用神判定步骤、六亲/财官/婚姻/事业/健康断法、输出模板。
**解读时必须引用该流派的真实规则，不编造，不跨流派混用设定**（如平衡论的"隔不作用""旺衰百分比"是特有设定，盲派不用）。

### Step 4 · 输出格式
建议按此结构给结论（可按问题裁剪）：
1. **命盘速览**：四柱 + 十神 + 日主 + 五行强弱一句话。
2. **核心判定**（按流派）：旺衰、格局、用神忌神（或盲派的宾主/做功）。
3. **人生维度**：性格、六亲、婚姻、财运、事业、健康（择要，标注不确定项）。
4. **大运提要**：当前/下一步大运的吉凶倾向与应期信号（冲、伏吟、岁运并临等）。
5. **诚实边界**：这是传统术数方法论推演，非科学预测。

## 排盘口径速查（引擎已实现，供核查）

| 项目 | 口径 |
|------|------|
| 年柱 | 以**立春**为界（北京时间），立春前属上一年 |
| 月柱 | 以**交节**（12 节：立春/惊蛰/清明/立夏/芒种/小暑/立秋/白露/寒露/立冬/大雪/小寒）为界，五虎遁起月干 |
| 日柱 | 儒略日算法（已双锚校准 1965-12-16=甲辰、2000-01-01=戊午） |
| 时柱 | 五鼠遁；**23:00–23:59 为晚子时，归次日且按子时** |
| 大运 | 阳男阴女**顺**、阴男阳女**逆**；起运岁数 = 到交节实足天数 ÷ 3 |
| 神煞 | 天乙、文昌、羊刃、禄神、桃花、驿马、华盖（空亡按旬） |
| 纳音 / 旬空 / 长生 | 标准 60 甲子循环（已修正干支配对算法） |

> 口径依据用户提供的 60+ 篇命理资料实测提炼，并经多例交叉验证（含黄勇智大纲 1965 造、以及若干公开命例）。

## 诚实边界

- 排盘是天文/历法算法，可复核；解读是传统命理方法论，本技能提炼其**推断流程**，不对"八字预测人生"的有效性做任何科学背书。
- 不同流派对同一八字常有冲突结论（如盲派重做功、平衡论重用神、黄勇智重日干喜忌），已分文件隔离，不强行统一。
- 旺衰百分比、宫位力量比较、断语配置等多为经验约定，存在主观空间，解读须标注不确定项。
- 若用户提供出生地要求真太阳时，本版引擎按输入时间直排，请明确告知该限制。
