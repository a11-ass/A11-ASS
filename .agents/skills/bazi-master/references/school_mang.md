# 流派二 · 盲派（宾主 / 体用 / 做功）

> 盲派（段建业、卜文一系）重"组合做功"，**不先论旺衰、不重神煞、不重格局名称**，
> 而看日主用什么"体"去获取"用"（财官）。本文件为盲派解读口径的可操作框架。
> 注：盲派内部门派细分多，以下为段氏/卜文主流方法的共识性提炼。

## 总纲：宾主 · 体用 · 做功
- **宾主**：日主及其"体"（日干、日支、禄、比劫、印——自己拥有的工具）为**主**；财、官、食伤（外界、要去获取的成果）为**宾**。
- **体用**：体=日主可用的工具（禄、比、印，食伤有时作体）；用=财官（目标）。
- **做功**：体对用发生"制、化、生、合、冲、库、刑穿"等作用，把宾位的财官"拿到手"即为得。
  - 做功方式优先级参考：制（克）＞ 化（泄生）＞ 合 ＞ 冲 ＞ 墓（入库）＞ 刑穿。
- **富贵看做功效率**：做功大且干净（宾位财官被有效制/合/库）→ 富贵的层次高；做功无力或"反局"→ 贫贱、虚浮。

## 反局与贼运（凶的信号）
- **反局**：该制的反被制、该合的被合走、用神（宾位目标）被"我所不喜"的方式破坏。如财星本要被制来取，却反被印/比生护 → 求财不得。
- **贼运**：大运流年出现"反局"配置，或把原局有用的做功路线切断，为该阶段凶应。

## 十神具体取象与断法
- **官杀**（工作、权力、丈夫（女）、压力）：官杀为"用"被制/化 → 得权得贵；官杀攻身无制 → 压力、官非、丈夫缘薄。官杀入墓/被合 → 权力不显或夫缘淡。
- **财星**（财富、妻子（男）、父亲（偏财））：财被制/合/入库 → 得财；财被比劫夺、被冲刑穿 → 破财、妻不稳。男命妻星=正财，正财受克/入墓/被合 → 婚姻波折。
- **印星**（文书、母亲、单位、学历、庇护）：印为"体"不宜被财坏（坏印 → 失学历、失单位、母病）；印化官杀 → 以文求贵。
- **食伤**（才华、口才、子女（女）、泄秀）：食伤制杀 → 威权、技术立身；食伤生财 → 技艺/口才生财；女命食伤为子女星。
- **比劫 / 禄**（自己、同辈、身体）：禄被冲/穿 → 身体伤、奔波；比劫夺财 → 破财、争妻、同辈拖累。

## 婚姻断法（盲派侧重）
- 男命看**正财**（妻星）之有无、受克/合/墓/冲；无财星则看**日支**（夫妻宫）。
- 女命看**正官**（夫星）；无官则看日支。
- 日支（夫妻宫）喜静，**忌冲、刑、穿、合走**；宫位被坏 → 婚姻不稳或配偶身体/缘分差。
- 财官"被合走"（尤其被它支合去）→ 配偶有外情或聚少离多信号。

## 六亲断法（宫位为主、星为辅）
- 年柱=祖上/父，月柱=父母/兄弟，日支=夫妻，时柱=子女。
- 宫位宜静、宜为喜用、宜不受冲刑穿；宫位受坏或被忌神占据 → 该六亲缘薄或凶。
- 星（十神）与宫同参：星宫皆喜→好且帮；星宫皆忌→凶大；星喜宫忌/宫喜星忌→力量比较断。

## 刑冲合害要点（盲派特别重视）
- **穿（害）**：子未、丑午、寅巳、卯辰、申亥、酉戌——穿的力量隐蔽而狠，常主暗疾、暗破、暗中伤人。
- **墓库**：辰（水/财官墓）、戌（火/印墓）、丑（金/比墓）、未（木/食伤墓）；财官入墓宜开库（冲）方得，闭库则难取。
- **暗合**：寅丑、卯申、午亥等——暗中之合，主私下关联、隐情。
- **刑**：寅巳申（无恩）、丑戌未（恃势）、子卯（无礼）——主反复、纠缠之灾。

## 输出模板（盲派口径）
1. 点明日主之"体"（禄/印/比/食伤）与所求之"用"（财官）。
2. 做功路线：日主用什么体、如何制/化/合宾位的财官；做功大小定富贵层次。
3. 反局/贼运：指出原局或某步大运的"反局"信号。
4. 分维度：婚姻（妻/夫星+日支）、六亲（宫位）、财运（财之制合库）、事业（官杀制化）、健康（禄/体受冲穿）。
5. 诚实边界：盲派重组合不重旺衰，结论偏"象法"，与平衡论用神口径不同，不强行统一。

## 与平衡论的主要分歧（避免混用）
- 盲派**不先排旺衰、不立用神忌神**，而看做功；平衡论的"隔不作用""旺衰百分比"在盲派体系中不适用。
- 盲派重"宾主制化""刑穿墓库"，平衡论重"五行平衡""星宫同参"——两套语言，解读时各用各的。
