# 流派三 · 黄勇智体系（日干喜忌 / 十神意向 / 大运吉凶）

> 黄勇智《八字大纲版》一系：以**日干为中心**建立系统化的喜忌与十神意向，重视调候与格局，
> 并给出大量十神配置断语；大运流年看"用神进退"与原局组合引动。本文件为该口径的可操作框架。
> 注：黄氏对每日干有细化的"喜忌表/用神表"，以下为与其思路一致的通用骨架，具体请回查其大纲原文。

## 分析流水线
1. **定日干旺衰**（与平衡论类似：月令为主、看根气印比党众、不唯月令）。
2. **定日干喜忌**：据日干五行/阴阳，列出喜用与忌讳的五行（见下"日干喜忌提纲"）。
3. **十神意向**：看财官印食伤比在各柱的"有无、强弱、受克合墓"，定六亲与人事。
4. **格局与用神**：扶抑/从格/化格；取用神，并看用神在大运流年的进退、受生受克。
5. **大运吉凶**：大运干支对原局用神是"助用"还是"助忌"，引动何宫何十神。

## 日干喜忌提纲（通用骨架，黄氏细化版请查原文）
- **甲木（阳木）**：喜庚金（斧斫成材）、丙火（泄秀暖局）、丁火（伤官）；忌壬水过泛漂木、忌比劫争财。身弱喜水木印比，身强喜火金。
- **乙木（阴木）**：喜丙火（向阳）、癸水（润）、庚辛（修剪）；忌埋根之铁（庚多伤）。柔木喜甲藤萝系甲。
- **丙火（阳火）**：喜壬水（水火既济）、庚金（财）；忌戊土晦火、己土泄。身弱喜木火。
- **丁火（阴火）**：喜甲木（引灯）、庚金（财）、壬水（合）；忌丙夺光、己晦。灯烛之火喜夜生、忌旺土。
- **戊土（阳土）**：喜甲木（疏）、丙火（暖）、癸水（润）；忌金多泄、水多荡。高山之土喜有木疏。
- **己土（阴土）**：喜丙火（暖）、甲木（疏）、癸水（润）；忌乙木病、金水过寒。
- **庚金（阳金）**：喜丁火（炼）、甲木（财）、壬水（洗）；忌土多埋金、火过熔金。
- **辛金（阴金）**：喜壬水（洗）、丙火（温）、甲木（财）；忌土多埋、水寒。
- **壬水（阳水）**：喜戊土（堤）、丙火（财暖）、庚金（源）；忌己土浊、金寒水冷。
- **癸水（阴水）**：喜丙火（暖）、庚辛（源）、甲乙（泄）；忌己土浊、金寒水泛。

## 十神意向断法（黄氏偏重配置）
- **正官**：贵气、自律、工作、夫（女）；为喜透干清纯→官贵；混杂/伤官见官→官非。男命官杀也看事业。
- **七杀**：权威、压力、偏业、夫（女偏缘）；有制（食伤制/印化）→威权；无制攻身→压力灾。
- **正财**：稳定财富、妻（男）、务实；为喜旺逢生→富；被劫/冲→破财妻不稳。
- **偏财**：横财、父、偏缘；为喜→外财；为忌旺→浮财不聚。
- **正印**：学历、母亲、单位、庇护；为喜→文贵母慈；被财坏→失学历/单位。
- **偏印（枭）**：偏业、思想、继母；为喜有巧艺；为忌夺食→子女/口舌。
- **食神**：才华、子女（女）、福气、泄秀；为喜制杀生财→技艺立身。
- **伤官**：才华外露、叛逆、子女（女偏）、克官；为喜泄秀→艺术；见官→口舌官非。
- **比劫/禄**：同辈、自己、身强之源；为喜帮身；为忌→争财夺妻、破耗。

## 婚姻断法
- 男命以**正财**为妻星，女命以**正官**为夫星；星之不现则看日支（夫妻宫）。
- 妻/夫星为喜旺逢生→婚美；为忌旺逢生/受克→婚波折；星入墓、被合走、与日支刑冲→不稳。
- 日支夫妻宫宜静，受冲刑穿→婚姻动荡；宫位为喜→配偶助己，为忌→拖累。

## 财运 / 事业断法
- 身旺喜财、财旺逢生且无劫夺→富；身弱财旺为忌→求财辛苦。从财格财为用旺→大富。
- 官杀为用旺逢生/有制→官贵；身旺比劫旺不见官→无官且防官灾；从官格→仕途。

## 大运吉凶提要
- 大运干支生助原局**用神**→吉运；生助**忌神**→凶运。
- 用神"进"（得地、透干、逢生）→运势上扬；用神"退"（受制、入墓、被合）→运势下沉。
- 大运冲克原局关键宫位/用神（冲限运）、岁运并临、伏吟反吟→重大应期信号，须提示。

## 输出模板（黄氏口径）
1. 日干旺衰 + 日干喜忌（列出喜用/忌讳五行）。
2. 用神、忌神（天干地支具体字）+ 调候说明。
3. 十神配置要点（财官印食伤比在各柱的强弱与意向）。
4. 婚姻、财运、事业、六亲、健康择要（按喜忌与十神）。
5. 大运吉凶提要（用神进退、应期信号）。
6. 诚实边界：黄氏喜忌表为经验细化，断语随组合而变，标注不确定项。

## 与平衡论/盲派的分歧
- 黄氏更"日干中心 + 喜忌表驱动"，与平衡论"找全局平衡用神"方向一致但表述不同；二者都立用神，可互通。
- 与盲派"不立用神、看做功"根本不同；切换流派时不要混用"做功"与"用神忌神"两套语言。
