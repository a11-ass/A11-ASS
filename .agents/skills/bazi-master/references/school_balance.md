# 流派一 · 五行相对平衡论（新派 / 平衡论）

> 来源：《八字实战讲义》（赵知易、孙海义，弘易堂 2001）。本文件是该学派的可操作推断框架，
> 用于 bazi-master 的"平衡论"解读口径。**本学派特有设定：隔不作用、旺衰百分比表、不用生旺死墓绝表。**

## 核心心智模型（5 个）

1. **五行相对平衡论**：八字核心是找使五行"相对平衡"的平衡点（用神），而非看哪个五行旺。先问"哪里失衡？谁来补？"
2. **喜忌相对论**（喜非永喜、忌非永忌）：同一字随组合可互换吉凶——忌神制忌神→以吉断；用神受制不起好作用→以凶断。判断吉凶须看它在**本组合**中对日干的实际作用。
3. **隔不作用**（干支作用论）：只有相邻或本柱才发生生克耗泄；年干与日干隔月干不作用，遥克不计。这是旺衰/用神计算的硬规则。
4. **得时非旺、失时不衰**：旺衰不能只看月令当令，须四柱组合统观（月令约占 50%，但可被受制/党众改变）。
5. **星宫同参**（宫位六亲论）：十神不现时不盲断，转看宫位（年/月/日/时柱所代表的六亲空间），星与宫须同参。

## 方法论（7 步）

- **M0 排盘**：四柱、十神、大运（引擎已完成）。
- **M1 定旺衰五步法**：①查月令（四正月约 50%，四生/四墓月按百分比表）②看月令受制次数 ③论日支根气 ④看月干/时干/坐支直接作用 ⑤综定身旺/身弱（不唯月令）。
- **M2 分格局**：能扶抑→**扶抑格**；扶抑不了→**从格**（从强/从弱）。扶抑格再细分用官杀/比劫/枭印/食伤/财。
- **M3 取用神五法**：①扶抑 ②从旺 ③从弱 ④调候（夏喜官杀、冬喜财星，但不违日干喜忌）⑤通关（忌神对峙用中间五行化解）。
- **M4 用神成败与格局高低**：用神须有力（天地同参）、看位置（年月为喜用格局高、日时为低）、看远近（透干直接作用应吉大）。
- **M5 宫位六亲六条**：十神不现转看宫位；用神六亲不见应凶但宫位发挥用神作用→吉；宫忌亲用/亲忌宫用/同喜用等六类力量比较。
- **M6 应用篇断语模板**（性格/父母/兄弟/婚姻/财运/官贵/病伤/官非/子女/考学/寿元，各分扶抑格与从格两套）。
- **M7 寿元四法**：冲限运、伏吟、反吟、岁运并临——抓"动"的应灾信号，再用用神忌神受克定凶。

## 旺衰判定要点（经验表，节选）
- 月令旺度：四正（子午卯酉）之月当令五行约 50%；四生（寅申巳亥）、四墓（辰戌丑未）按月令五行取 15%~40% 不等。
- 日支为印比旺度约 15%，两次受制为 0；月干、时干、坐支直接作用于日干，坐支力最大。
- 月令两次受制则旺度不足 50%，三次为 0；四生/四墓月两次受制即为 0。

## 六亲定位（星宫同参）
- 父：偏财（星）/ 年柱、月干（宫）；母：正印（星）/ 月支（宫）。
- 兄弟：比劫（星）/ 月柱（宫）。夫妻：日支（宫）+ 男看正财、女看正官（星）。
- 子女：男看官杀、女看食伤（星）/ 时柱（宫）。
- 十神不现→转宫位；星宫冲突→看谁为喜用、谁贴身受制。

## 输出模板（平衡论口径）
1. 日主旺衰 + 格局类型（扶抑格·身旺/身弱，或从格）。
2. 用神 / 忌神（列出天干地支具体字，并标喜忌相对论中的"角色互换"提醒）。
3. 六亲、婚姻、财运、事业、健康择要（标注扶抑/从格分支）。
4. 大运吉凶提要 + 应期信号（寿元四法）。
5. 诚实边界：经验性约定，非精确算法。

## 常见误区（本学派强调避免）
- 死记断语、唯月令论旺衰、神煞/奇格异局定吉凶、把用神当恒吉。
- 与《滴天髓》"刑不足凭"相反，本学派主张"理清作用关系即可不论刑"，把冲/刑/伏吟反吟作应灾触发器。
